## 📂 Repository Structure

Each day has its own folder; each problem is a subfolder:

```text
Day-001/
├── README.md
├── 01-chessboard-cell-color/
│   ├── solution.py
│   └── notes.md
├── 02-youngest-family-member/
│   ├── solution.py
│   └── notes.md
└── 03-kth-unique-string/
    ├── solution.py
    └── notes.md

Day-002/
└── ...
```

### `solution.py`

Contains the solution/code for that problem (submitted + improved when relevant).

### `notes.md`

Contains a short reflection covering:

* Problem
* Critical thinking / approach
* Key idea
* What I learned
* Complexity
* Challenges / mistakes
* Possible improvements

### Day `README.md`

Daily progress table, takeaways, and reflection.

## 🧩 Daily Workflow

Every day follows the same basic process:

```text
1. Pick the day's challenge
        ↓
2. Understand the problem
        ↓
3. Attempt the solution
        ↓
4. Test & debug
        ↓
5. Document what I learned
        ↓
6. Commit to Git
        ↓
7. Push to GitHub
```
