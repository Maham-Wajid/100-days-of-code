## 📂 Repository Structure

Each day has its own folder:

```text
Day-001/
├── solution.py
└── notes.md

Day-002/
├── solution.py
└── notes.md

...
```

### `solution`

Contains the solution/code written for that day's challenge.

### `notes.md`

Contains a short reflection covering:

* Problem
* Approach
* Key idea
* What I learned
* Complexity
* Challenges / mistakes
* Possible improvements

---

## 🧩 Daily Workflow

Every day follows the same basic process:

```text
1. Pick the day's challenge
        ↓
2. Understand the problem
        ↓
3. Attempt the solution
        ↓
4. Test & debug
        ↓
5. Document what I learned
        ↓
6. Commit to Git
        ↓
7. Push to GitHub
```
